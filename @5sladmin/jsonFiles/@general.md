# general.json 配置文件說明文檔

## 檔案概述

`general.json` 是**人生第五季系統的核心配置映射表**，提供統一的常數值管理。此檔案為系統的各個功能模塊定義編碼對照、資料庫映射、狀態轉移、視覺樣式等，使系統各層（前端、後端、資料庫）保持一致性。

---

## 身份識別與內容分類系統 (idfor)

## 使用範例

### PHP 中使用配置

```php
<?php
// 載入配置
$config = json_decode(file_get_contents('general.json'), true);

// 獲取內容類型名稱
$idfor = $config['idfor']['4']; // 取得服務類型
echo "內容類型: " . $idfor['text'];         // 輸出：開放式服務
echo "資料庫表: " . $idfor['table'];       // 輸出：sv_service
echo "主鍵欄位: " . $idfor['idcol'];       // 輸出：sv_id

// 取得評分維度
foreach ($idfor['rating'] as $code => $rating) {
    echo "評分 $code: $rating\n";
}

// 取得操作類型
echo "操作類型 1: " . $idfor['otype']['1']; // 輸出：講座

// 取得視覺徽章
$badge = $config['actionbadge']['0'];
echo "<span class='badge$badge'>駁回</span>";
?>
```

### JavaScript 中使用配置

```javascript
// 前端取得狀態信息
const config = await fetch('general.json').then(r => r.json());

// 顯示發布狀態
const statusCode = 6;
const statusText = config.status[statusCode]; // "初審"
const badgeClass = config.badge[statusCode];   // "badge-step6"

// 建立徽章元素
const badge = `<span class="badge${badgeClass}">${statusText}</span>`;
```

## 維護建議

1. **新增映射值時**：確保在相關的所有對象中添加（例如 `status` 和 `badge`）
2. **評分維度**：保持 1-5 的評分標準一致
3. **資料庫引用**：若修改 `idfor` 中的表名或欄位，需同步更新相關 SQL 查詢
4. **版本控制**：記錄每次修改的日期、原因和影響範圍
5. **備份**：修改前建議備份此檔案
6. **跨系統驗證**：確認前端、後端、資料庫的編碼一致

## 重要說明

- 此檔案為單一真實來源 (Single Source of Truth)，所有模塊應參考此配置
- 許多編碼值保留了 9 作為「其他」或「封存」狀態
- 流程状態通常採 0-9 編號，便於顯示進度條
- 空字串鍵 `""` 用作欄位說明標籤，不代表實際編碼值
