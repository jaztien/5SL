# administrator.json 配置說明文件

## 檔案概述

`administrator.json` 是一個**權限管理系統的映射表**，用於定義使用者在系統中的授權狀態、管理等級和視覺顯示方式。此檔案包含三個主要課程商品：`status`、`authlevel` 和 `badge`。

---

## status 課程商品 - 授權狀態

定義使用者帳戶的授權狀況。

| 編碼 | 說明 | 用途 |
|------|------|------|
| 0 | 停權中 | 帳戶被暫停或凍結，無法使用 |
| 1 | 正常授權 | 帳戶有效且可用 |

空字串鍵 `""` 的值 `"--管理授權狀態--"` 作為欄位標籤，提供說明文檔。

---

## authlevel 課程商品 - 管理等級

建立一個**分層的權限等級系統**，共 10 個級別（0-9），從最低到最高權限。

### 等級分布

| 等級 | 職務 | 說明 |
|------|------|------|
| 0 | 未定權限 | 初始狀態，無特定權限配置 |
| 1 | 資料查詢人員 | 可查詢系統資料 |
| 2 | 客戶服務人員 | 負責客戶服務相關工作 |
| 3 | 一般操作者 | 執行日常系統操作 |
| 4 | 進階管理者 | 具有進階管理權限 |
| 5 | 工程技術人員 | 技術支援與維護 |
| 6 | 高級工程師 | 高級技術工程 |
| 7 | 高級管理者 | 高級系統管理 |
| 8 | 總工程師 | 工程部門最高職位 |
| 9 | 最高管理者 | 系統最高權限 |

### 應用方式

應用程式根據使用者的 `authlevel` 值判斷其能夠存取的功能和操作範圍。這種集中化配置允許無需變更程式邏輯即可進行權限調整。

---

## badge 課程商品 - 視覺指示器

將權限等級映射到 Bootstrap CSS 類名，用於在使用者介面中視覺化顯示權限狀態。

| 等級 | CSS 類名 | 顏色/含義 |
|------|----------|----------|
| 0 | badge-danger | 紅色（危險/停權） |
| 1 | badge-success | 綠色（正常） |
| 2 | badge-primary | 藍色（主要） |
| 3 | badge-warning | 黃色（警告） |
| 4 | *未定義* | - |
| 5 | *未定義* | - |
| 6 | badge-warning | 黃色（警告） |
| 7 | badge-warning | 黃色（警告） |
| 8 | badge-warning | 黃色（警告） |
| 9 | badge-dark | 深灰色（最高） |

**注意**：等級 4、5 在此配置中未定義 badge 樣式。

---

## 使用範例

```php
// 根據 authlevel 判斷權限
$authlevel = $user['authlevel'];
$levelName = $config['authlevel'][$authlevel];
$badgeClass = $config['badge'][$authlevel] ?? 'badge-secondary';

echo "<span class='badge{$badgeClass}'>{$levelName}</span>";
```

## 維護建議

1. **新增等級**：同時在 `authlevel` 和 `badge` 中添加對應的鍵值對
2. **停用等級**：不要直接刪除，改為註記為已停用
3. **備份**：修改前建議備份此檔案
4. **版本控制**：記錄每次修改的原因和時間
